# H5: separate event magnitude from conditional direction

This is an additional development comparison motivated by the first stock calibration diagnostics, specified before this experiment reads stock forward outcomes. The original study, its hypotheses and its three scientific source files stay frozen. This amendment is not retrospectively described as the original preregistration or a pristine OOS experiment.

The original stock calibration shows strong large-move ranking but conditional direction AUC near 0.505 for the full-feature three-class and independent binary models. Signed-return regression has conditional direction AUC near 0.541 but much weaker large-move AP. This motivates testing a model-objective mismatch: scarce directional endpoint observations can be dominated by ordinary outcomes when the same loss fits all origins.

Use exactly the current-feature numeric columns, native row keys, native endpoint indicators, dates and supported float32 domain of the parent study. No extra feature, peer input, nominal column, source data or history is added. Retain every native scoring origin and all original feature states. Both stages use the same 600-tree maximum, depth six, seed, regularization, early-stopping dates and 50-round stopping rule as the two independent binary heads.

Stage one fits the logical union codebook of the two original native endpoint indicators, estimating P(big). Stage two fits the original native up indicator on known native big-event train rows and big-event early-stopping rows, estimating P(up | big). The two side scores are P(big) times P(up | big), and P(big) times one minus P(up | big). No price arithmetic or new LOB/Trade formula constructs the labels. Conditional fitting changes the training population deliberately; it does not filter feature availability or scoring origins.

Weights begin with the parent's equal symbol-day mass and 40-calendar-day recency rule on all known endpoint rows. The conditional stage retains those relative weights on its big-event rows and renormalizes their mean to one. It does not equalize each symbol-day's event count or use class reweighting. Report the support and this changed effective conditional population.

The sole control is the already fixed `current_binary` model pair. Own calibration nomination precedes own forward scoring. Calibration requires at least two percent relative mean AP gain, at least 0.01 conditional direction AUC gain, no within-symbol-day AUC loss greater than 0.01, and no loss of correct-minus-opposite top-one-percent precision. Forward requires a positive five-percent lower paired daily-AP bound under the existing three-day block bootstrap, at least 0.01 conditional direction AUC gain, the same ranking/precision guards, non-overlap AP not below control, and the existing minimum non-overlap event/day support. A calibration failure is reported as rejection even if later descriptive forward values look favorable.

The two stages together use two binary models, matching the control's number of heads and maximum per-head budget. Their fitting populations and early-stopping objectives differ as the intended training treatment. The experiment waits for the parent study to finish before allocating large training pools, to avoid concurrent memory pressure. Its protocol is frozen first, including the parent protocol, projections, control-model identities and source files. It reuses verified native projections; it does not regenerate source observations or substitute missing days.

Native composition and baseline integration are attempted only if the predeclared predictive comparison passes. Existing CBPredictor accepts independent up/down heads; the factorized heads must not be renamed as ordinary up/down models. Until its own explicit native route is implemented and actual-model parity passes, this method is an offline development result.
