## Hypotheses and exact representations

Can a coherent representation of physical movement/activity opportunity,
session/price anchors, confidence-weighted demand and net observed supply replace
the large legacy feature universe without losing complete predictive power?
Given that local context, does a prior joint flow/price reference reveal unusual
directional response and movement information beyond relative activity alone?

The three prospective arms, in this exact order, are:

1. `baseline`: a fresh fit of the immutable legacy `current_nominal` selection,
   3254 original numeric columns and 132 original categorical columns. Its raw
   scales make it a scientific control, not a cross-symbol-normalized admission.
2. `c15`: the source-audited C18 numeric order in
   `H15_COMPACT_C_SOURCE_AUDIT.md`, omitting exactly the three
   `FlowResponseSurprise.0.{flow_surprise0,response_innovation0,response_coupling0}.0`
   descriptors, and retaining exactly `CurrentBook.1.sticky_side.0` and
   `PriceFormationPath.0.cause_dominant.1` categories. This is 15 numerics +2 cats.
3. `c18`: the exact audited C18+2 order, including those three native conditional
   innovations/coupling fields from the existing 300s reference. This is 18
   numerics +2 cats. All shared C15 fields and categories are bit-identical.

The three FlowResponse descriptors already exist in the full original 3296
numeric projection although the legacy selected 3254 control excludes them.
No new feature arithmetic is implemented in Python. All quantities are original
C++ FeatureModule outputs, selected by exact descriptor. No new native replay,
window extension, HPO, approximate variant or row cache is needed.

The flow surprise uses prior capacity-relative flow/second dispersion. Response
innovation removes the prior joint slope and scales the tick/second residual;
coupling records prior association. Prior completed intervals establish the
reference before the current interval enters it. This tests conditional response
information, not an identified informed-trader or economic causal mechanism.
The other 15 fields retain physical tick variation, spread and session range,
directional anchors, relative activity and displayed-capacity normalization.
The exact units, positive denominators and zero/missing limits remain those in
the source audit. Standardizing an innovation does not imply that every other
factor should be z-scored.

Keep original producer vintage: the original nine FlowResponse fields can encode
unfinished references as NaN where the corrected later producer uses -inf.
V5 must not recode those states or import later rebuilt values. All native
numeric sentinels, signed zero and categorical strings stay unchanged. No feature
availability mask may remove an origin. Native missing values can carry context;
apparent gains cannot establish finite-value information independently of that
availability without a later separate study.
